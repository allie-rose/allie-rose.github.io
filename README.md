# My AI Portfolio

A simple portfolio site showing AI projects, research, and work experience. It's hosted free on GitLab Pages.

## How to update the content

Edit **`content.js`**. It's the only file you need to touch. Change the text inside the quotes, and copy a `{ ... },` block to add another project, paper, or job. Each project's `details` section fills in its own page (`project.html?p=<slug>`).

To add a résumé, put `resume.pdf` in this folder and set `resume: "resume.pdf"` in `content.js`.

## Where it lives

The site is hosted for free in two places, both built from the repo `allie-rose/allie-rose.github.io`:

- **Vercel:** https://allierose.vercel.app
- **GitHub Pages:** https://allie-rose.github.io

## How to update it

Edit `content.js` (you can even do it on github.com: open the file, click the pencil icon, and commit). Both Vercel and GitHub Pages republish the site about a minute after every change.

## Preview on your computer

Double-click `index.html` to open it in your browser.
